# Graphite Video Engine

Software / Video Art

The Graphite Video Engine is a Max MSP library built to create abstract video art. The library is inspired by analogue audio synthesisers, using an architecture that combines video and control signals to form a non-hierarchical patching experience. Every part of the system is a shader module that can be interconnected with any other module, producing complex and chaotic GPU render pipelines.
